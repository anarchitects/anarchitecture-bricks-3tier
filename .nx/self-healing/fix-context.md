## Analysis & Reasoning
The Nx 23.1.3 migration automatically inserted `"ignoreDeprecations": "6.0"` into every project-level and root `tsconfig.json` in the workspace.

TypeScript's `--ignoreDeprecations` option only accepts version strings that correspond to TypeScript major releases in which the relevant deprecations were introduced. As of this workspace's TypeScript 5.x toolchain, the only valid value is `"5.0"`. The string `"6.0"` references a TypeScript version that does not yet exist, so the compiler rejects it with `TS5103: Invalid value for '--ignoreDeprecations'` before any project code is even compiled.

The fix changes the value from `"6.0"` to `"5.0"` across all 20 affected `tsconfig.json` files. This preserves the intent of the migration — suppressing TypeScript 5.x deprecation warnings to allow the codebase to compile cleanly after the Nx upgrade — while using the value the installed TypeScript version actually accepts.
