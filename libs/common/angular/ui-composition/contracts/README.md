# @anarchitects/common-angular-ui-composition/contracts

Contracts for slot names, template names, alias compatibility, and
composition schema registration.

## Exposes

- `KnownAnxSlotName`, `AnxSlotName`, `ANX_SLOT_ALIASES`
- `KnownAnxTemplateName`, `AnxTemplateName`
- `AnxCompositionSchema`, `ANX_COMPOSITION_SCHEMA`
- `provideAnxCompositionSchema(...)`

## Slot compatibility aliases

- `anxCardHeader -> header`
- `anxCardFooter -> footer`
- `anxStart -> start`
- `anxEnd -> end`
- `anxActions -> actions`
- `anxLabel -> label`
- `anxHint -> hint`
- `anxError -> error`
