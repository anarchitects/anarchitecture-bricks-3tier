# @anarchitects/common-angular-ui-layouts/defaults

Built-in layout renderers and registrations.

Exports:

- default renderer components for `form`, `list`, and `detail` families
- built-in layout definitions
- `provideAnxDefaultLayouts()`

Built-in layouts:

- forms: `form:stacked`, `form:grid`, `form:inline`, `form:card`
- lists: `list:list`, `list:grid`, `list:card`, `list:table`
- detail: `detail:page`, `detail:card`, `detail:sidebar`

Renderers compose shared UI primitives and Phase 2.5 composition contracts.
